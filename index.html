A simple way to learn with both

1 · START WITH BODE

Place one LHP pole at 10 Hz. Change it to an RHP pole. The magnitude stays the same; the phase changes direction.

2 · TRY A ZERO

Repeat with a zero. An RHP zero adds rising magnitude while its phase falls. This differs from an RHP pole, which is an unstable mode.

3 · OPEN NYQUIST

Enter a transfer function and watch its complex response. Try the built-in examples, including the RHP-zero example.

For stability, the Nyquist curve must be interpreted with the loop definition and the number of open-loop RHP poles. A plot alone is not a complete stability verdict.
